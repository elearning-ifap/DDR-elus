Version GitHub Pages — Droits, devoirs et responsabilités de l'élu

Déploiement :
1. déposer index.html, le dossier media, le dossier resources et .nojekyll à la racine du dépôt ;
2. activer GitHub Pages sur la branche principale / racine ;
3. ouvrir l'URL GitHub Pages du dépôt.

Le module fonctionne hors LMS : en l'absence d'API SCORM, le noyau bascule automatiquement en mode prévisualisation.
