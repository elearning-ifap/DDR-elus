Version GitHub Pages — Droits, devoirs et responsabilités de l'élu
Noyau : v1.8.1
UX : grammaire commune du dispositif, alignée sur les conventions stabilisées dans le module Budget.

Évolutions de cette version :
- plan principal réduit aux 5 missions ;
- progression visible dans chaque mission et dans le plan ;
- repère « mission + position locale » sur chaque écran pédagogique ;
- navigation précédente / suivante contextualisée ;
- grammaire en 4 temps : situation & décision / conséquences & repères / ma méthode / nouvelle décision ;
- visionneuse grand format pour les 4 mémos visuels ;
- responsive tablette et mobile conservé.

Déploiement :
1. déposer index.html, le dossier media, le dossier resources et .nojekyll à la racine du dépôt ;
2. activer GitHub Pages sur la branche principale / racine ;
3. ouvrir l'URL GitHub Pages du dépôt.

Le module fonctionne hors LMS : en l'absence d'API SCORM, le noyau fonctionne en mode prévisualisation.
